## Scope
In:
- Static site with no build step (plain HTML/CSS/JS) so it can be served from GitHub Pages or any host.
- Home page: hero, project index grouped by series, drawing plates, about, contact.
- Project detail page rendered from a single data file (`js/data.js`).
- Responsive down to mobile, keyboard focus visible, reduced-motion respected.

Out (deliberately):
- CMS, build tooling, frameworks, analytics, contact form backend.
- Real photographs and project write-ups beyond what the owner supplied.
- Korean or Japanese language versions.
- Claims of professional registration or titles the owner did not state.

## Constraints
- Content lives in `js/data.js`; layout must not need editing to add, remove, or regroup a project.
- No external dependencies other than Google Fonts.
